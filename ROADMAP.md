# Development roadmap

## v0.1.0 — Initial alpha

- [x] CPU and RAM inventory
- [x] Local Ollama connectivity and installed model listing
- [x] Installation and usage documentation

## Planned: benchmarking

- [ ] Full CPU name and GPU detection
- [ ] Reproducible token generation speed and model load time measurements
- [ ] Peak system memory measurements during inference
- [ ] Export local benchmark results as JSON
- [ ] Automated tests with mocked Ollama responses

## Planned: configuration recommendations

- [ ] Compare context sizes and supported inference settings
- [ ] Report latency, throughput and memory trade-offs
- [ ] Evaluate output quality using reproducible tasks
- [ ] Recommend settings only after measurement and allow users to review them

## Longer-term ideas

- [ ] Optional graphical interface
- [ ] Support additional local inference backends
- [ ] Broader hardware and operating system testing

These are development goals, not promised release dates or guaranteed performance improvements.
